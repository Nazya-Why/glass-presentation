retrieval, login bypass, DBMS fingerprinting, listing DB contents, UNION
column count). Vertical top-to-bottom scroll deck over a real-time
liquid-glass WebGL2 background.

Open `index.html` in Chrome — no server or build step needed.

- Scroll (wheel / trackpad) or ↓ ↑ / Space to move between slides, `F` — fullscreen
