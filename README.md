# Glass presentation

15-slide HTML presentation with a real-time liquid-glass WebGL2 background
(ray-marched glass ribbons, spectral dispersion, bloom, depth of field, particles).

Open `index.html` in Chrome — no server or build step needed.

- Arrows / Space / click — navigate, `F` — fullscreen
- `?q=auto` — adaptive quality, `?q=0.75` — lower fixed quality, `?q=2` — supersampling
- `#5` — open on slide 5
